Spiegazione dei concetti Tailwind CSS utilizzati
1. Struttura Base
Utility-first: Tailwind usa classi atomiche che corrispondono a singole proprietà CSS

Responsive design: Le classi sono responsive-by-default (es. md:, lg:)

2. Classi principali usate nel modulo
Layout:

flex, items-center, justify-center - Centratura verticale e orizzontale

w-full, max-w-md - Larghezza piena con massimo di larghezza media

space-y-4 - Spaziatura verticale tra elementi figli

Stili per gli input:

border, border-gray-300 - Bordo grigio chiaro

rounded-md - Bordi arrotondati

px-4, py-2 - Padding orizzontale e verticale

Stati dinamici:

focus:outline-none - Rimuove l'outline di default al focus

focus:ring-2, focus:ring-blue-500 - Aggiunge un anello blu al focus

focus:border-transparent - Nasconde il bordo durante il focus

transition-all, duration-200 - Animazione fluida dei cambiamenti

Stili per il bottone:

hover:bg-blue-700 - Cambia colore al passaggio del mouse

focus:ring-offset-2 - Aggiunge spazio tra il bottone e l'anello di focus

3. Logica degli stati
Focus: Quando l'utente clicca o tabba su un input, le classi focus: vengono applicate

Active: Quando l'input è attivamente cliccato (mentre si tiene premuto il mouse)

Hover: Quando il mouse passa sopra un elemento

4. Transizioni e animazioni
transition-all - Applica transizione a tutte le proprietà animabili

duration-200 - Durata dell'animazione (200ms)

5. Approccio utility-first vs CSS tradizionale
Invece di scrivere CSS personalizzato:
.input-field {
    border: 1px solid #d1d5db;
    border-radius: 0.375rem;
    padding: 0.5rem 1rem;
}

.input-field:focus {
    outline: none;
    box-shadow: 0 0 0 2px #3b82f6;
    border-color: transparent;
}

Con Tailwind usiamo direttamente classi utility:
<input class="border border-gray-300 rounded-md px-4 py-2 focus:outline-none focus:ring-2 focus:ring-blue-500 focus:border-transparent">

Vantaggi di questo approccio:
Coerenza: Tutti gli input avranno lo stesso stile

Mantenibilità: Nessun CSS separato da gestire

Performance: Nessun CSS non utilizzato nel bundle finale

Rapidità di sviluppo: Modifiche direttamente nel markup

Tailwind CSS permette di costruire interfacce complesse mantenendo il CSS sotto controllo e con ottime performance.
